# 퍼스널 컬러 톤 비교 팔레트

이 파일은 `slides/personal_color_tone_palette.html`의 원본 메모입니다.
최종 슬라이드는 화면에 텍스트 없이 색상 면만 보이도록 구성했습니다.

## 슬라이드 순서

각 색상 묶음은 `섹션 페이지 -> 단색 페이지들` 순서로 넘긴다.
단색 페이지는 얼굴을 직접 대보는 용도라 화면 전체를 한 가지 색상으로만 채운다.

1. 4계절 전체 비교 섹션
2. 4계절 전체 비교 단색 페이지 16장
3. 봄 웜 섹션
4. 봄 웜 단색 페이지 20장
5. 여름 쿨 섹션
6. 여름 쿨 단색 페이지 20장
7. 가을 웜 섹션
8. 가을 웜 단색 페이지 20장
9. 겨울 쿨 섹션
10. 겨울 쿨 단색 페이지 20장
11. 웜톤 비교 섹션
12. 웜톤 비교 단색 페이지 24장
13. 쿨톤 비교 섹션
14. 쿨톤 비교 단색 페이지 24장
15. 라이트 톤 비교 섹션
16. 라이트 톤 비교 단색 페이지 24장
17. 딥 톤 비교 섹션
18. 딥 톤 비교 단색 페이지 24장
19. 포인트 컬러 비교 섹션
20. 포인트 컬러 비교 단색 페이지 24장

총 페이지 수: 섹션 10장 + 단색 216장 = 226장.

## 조작

- 섹션 페이지의 오른쪽 위 버튼, `F` 키, 더블클릭으로 전체화면을 켜고 끈다.
- 전체화면 상태에서도 좌우 클릭, `←`/`→`, 스페이스, 모바일 스와이프로 페이지를 넘긴다.
- 단색 페이지에는 얼굴 테스트를 방해하지 않도록 버튼을 숨긴다.
- 화면 아래의 작은 섹션 네비게이션으로 원하는 퍼스널 컬러 묶음으로 바로 이동한다.

## 색상 설계

- 봄 웜: peach, coral, warm pink, clear yellow, apple green, aqua
- 여름 쿨: powder pink, mauve, lavender, mist blue, soft mint, slate
- 가을 웜: camel, terracotta, rust, olive, moss, deep teal
- 겨울 쿨: black, white, fuchsia, true red, cobalt, emerald

> Note: 발표용 HTML은 섹션 페이지에서만 퍼스널 컬러명을 보여주고, 단색 페이지는 얼굴 테스트를 위해 가시 텍스트 없이 색상 하나만 표시한다.
